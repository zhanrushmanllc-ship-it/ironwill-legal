Lock In, Son — How the Monthly Draw Is Checked

This page is the algorithm referred to in section 6 of the Official Rules. It lets anyone recompute a month's winners and alternates from the published values. It uses only SHA-256 and integer arithmetic, so any programming language gives the same result.

1. What is published

Each eligible entry gets a random entry ID, such as 2026-10_Q7c0LmZ2pX9aT4vB8nR1. Entry IDs contain no names, email addresses or account details. Mail entries get IDs the same way and are drawn together with app entries.

ValueWhat it is
Entry listEvery eligible entry ID for the month
FingerprintSHA-256 of the sorted entry list (step 2), recorded before the seed exists
Seed32 random bytes, written as 64 lowercase hex characters, generated only after the fingerprint was recorded
Number of winners (n)The month's number of prizes, or the number of eligible entries if that is smaller
AlternatesThe entry IDs that follow the winners in the same shuffle, in order

After staff confirm a month's result, the fingerprint, the seed and your own entry ID are shown in the app's Draw tab. We email all of these values, including the full entry list and the alternates, to anyone who asks at support@zhanrushmanllc.com; mail entrants also get their own entry ID that way.

2. The algorithm

  1. Sort the entry IDs in ascending order of their UTF-8 bytes. For the ASCII IDs used here this is ordinary string order, with capital letters before lowercase letters.
  2. Fingerprint = lowercase hex of SHA-256 of the sorted IDs joined with commas (UTF-8). It must equal the published fingerprint.
  3. Random number stream. Let S be the 32 seed bytes. Block c (c = 0, 1, 2, …) is SHA-256(S followed by c as an 8-byte big-endian integer). Each block is cut into eight 4-byte big-endian unsigned integers, and the blocks follow one another: block 0's eight numbers, then block 1's, and so on.
  4. Unbiased number below a bound. To get r with 0 ≤ r < bound: limit = 2³² − (2³² mod bound); take the next number u from the stream; if u < limit, r = u mod bound; otherwise discard u and take the next one.
  5. Shuffle the front of the list. Let a be the sorted list, m its length, and k = min(n, m). For i = 0, 1, …, k − 1: j = i + (number below m − i); swap a[i] and a[j]. The winners are a[0] … a[k − 1], in the order drawn.
  6. Alternates. A = min(3 × number of prizes, m − n), or 0 if that is negative. Repeat step 5 from the start of the same stream with n + A instead of n. The first n entries are the same winners; the next A entries are the alternates, in order.

When a winner forfeits (Official Rules section 7), the prize goes to the next alternate who hasn't been used yet. All prizes in a month share this one order, and each prize can pass to at most three alternates.

3. Reference implementation (Python 3, standard library only)

import hashlib

def sorted_ids(ids):
    for entry in ids:
        if entry == "" or "," in entry:
            raise ValueError(f"bad entry id {entry!r}")
    result = sorted(ids, key=lambda s: s.encode("utf-8"))
    if len(set(result)) != len(result):
        raise ValueError("duplicate entry id")
    return result

def entries_hash(ids):
    return hashlib.sha256(",".join(sorted_ids(ids)).encode("utf-8")).hexdigest()

def uint32_stream(seed_hex):
    seed = bytes.fromhex(seed_hex)
    assert len(seed) == 32
    counter = 0
    while True:
        block = hashlib.sha256(seed + counter.to_bytes(8, "big")).digest()
        for offset in range(0, 32, 4):
            yield int.from_bytes(block[offset:offset + 4], "big")
        counter += 1

def pick(ids, seed_hex, n):
    entries = sorted_ids(ids)
    stream = uint32_stream(seed_hex)

    def below(bound):
        limit = 2**32 - (2**32 % bound)
        while True:
            value = next(stream)
            if value < limit:
                return value % bound

    count = min(n, len(entries))
    for i in range(count):
        j = i + below(len(entries) - i)
        entries[i], entries[j] = entries[j], entries[i]
    return entries[:count]

def pick_with_alternates(ids, seed_hex, n, prize_count):
    alternates = max(0, min(3 * prize_count, len(ids) - n))
    order = pick(ids, seed_hex, n + alternates)
    return order[:n], order[n:]
